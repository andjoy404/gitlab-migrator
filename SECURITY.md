# Security policy

## Reporting a vulnerability

Do not report credentials, authentication bypasses, command-injection issues,
or other vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected command, version or commit, reproduction steps, impact,
and any suggested mitigation. Remove real GitLab tokens, SSH keys, hostnames,
and exported customer data from the report.

If private vulnerability reporting is not enabled, contact the maintainer
privately through their GitHub profile and ask for a secure reporting channel.

## Supported versions

Security fixes are provided for the latest release on the default branch.
